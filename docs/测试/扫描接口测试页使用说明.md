# 扫描接口测试页使用说明

## 访问入口

启动包含测试页的本机服务后，打开：

<http://127.0.0.1:17653/test>

页面由扫描服务同源提供，使用原生 HTML、CSS 和 JavaScript，不依赖第三方 CDN 或前端构建工具。首次新增 `/test` 路由后需要重启服务；后续只修改 HTML 文件时刷新页面即可。页面源文件为 `app/web/scanner-test.html`。

## 操作顺序

1. 点击“检查健康状态”，确认服务和扫描工作进程就绪。
2. 点击“读取设备”，选择扫描仪；需要时点击“查询全部能力”。
3. 设置进纸模式、分辨率及可选参数，点击“创建新任务”，或读取并选择历史任务。
4. 放好测试纸后点击“开始扫描”。ADF 连续扫描到无纸；双面时每一面分别保存。开始前有确认提示，打开页面不会自动进纸。
5. 从实时事件查看进度，按需停止扫描；读取页面列表后选择页面，查询详情、读取原图或缩略图并下载。

“应用参数并重查能力”与“开始扫描”使用同一组固定参数及附加 JSON 配置。前者会设置设备参数，但不开始图像传输。所有参数仍由服务按当前设备能力校验。

## 覆盖范围

| 分组 | 可调用接口 |
| --- | --- |
| 服务 | `GET /api/v1/health`、`GET /api/v1/info` |
| 设备与能力 | `GET /api/v1/devices`、设备 Capability 查询、`POST /capabilities/resolve` |
| 任务与扫描 | 创建、列表、详情、删除任务，以及 `/scan/start`、`/scan/stop`、`/scan/complete` |
| 页面与文件 | 页面列表（含 `afterSequence` 增量查询）、页面详情、缩略图、原图和页面删除 |
| 实时事件 | `WS /api/v1/events`，支持可选 `taskId` 过滤、手动连接和断开，以及当前任务和页面自动刷新 |

共覆盖现有全部 17 个 HTTP 接口和 1 个 WebSocket 接口。新增页面入口不作为扫描业务 API 加入 OpenAPI 清单。

## 结果与删除

- 请求区显示实际方法、URL、请求体、HTTP 状态、耗时和原始响应；保留最近 30 条请求。
- 图片通过文件接口读取并以临时 Blob 地址预览和下载，不重新编码原图。
- 事件区保留最近 100 条事件；断开事件连接或关闭网页不会停止扫描任务。
- 删除页面或任务会删除对应记录及本机文件，页面执行前会提示确认。
- 本测试页不自动发起扫描、删除或 Capability 设置；健康检查会在页面打开时读取一次。
